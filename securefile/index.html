SecureFile Vault

A Google Drive-style file vault that stores every file's content exactly once. Upload the same file a hundred times and it costs the storage of one, while each user's quota stays accurate.

Live demo is being redeployed. Overview below.

How it works

  • Content-addressed storage: each upload is SHA-256 hashed and stored once as a blob, with per-blob and per-user reference counts.
  • Safe deletes: a blob shared by other files is protected from deletion at the database level.
  • Honest quotas: usage is tracked both as uploaded and as actually stored, and the dashboard shows the savings.
  • Sharing: public/private files, per-user shares, tags, and an admin panel with system-wide analytics.

Security

  • JWT authentication with bcrypt password hashing, and a separate admin auth system
  • Rate limiting, CORS protection and per-file access control
