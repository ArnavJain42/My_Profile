SecureFile Vault

A Google Drive-style file store that keeps each file's content once. Upload the same file a hundred times and it takes the space of one, while every user's quota stays honest.

The live demo is being redeployed. Until then, this page describes how it works.

How it stores files

  • Each upload is hashed with SHA-256 and stored once as a blob, with a reference count per blob and per user.
  • A blob that other files still point to cannot be deleted; the database refuses.
  • Quotas track both what a user uploaded and what is actually stored, and the dashboard shows the difference.
  • Files can be public or private, shared with named users, and tagged. An admin panel shows usage across the system.

How it keeps them safe

  • JWT sign-in with bcrypt-hashed passwords, and a separate sign-in for admins.
  • Rate limiting, CORS rules and access checks on every file.

What it is built with

Go and gqlgen for the GraphQL API, PostgreSQL with sqlc queries and goose migrations, React and Tailwind for the interface, Docker and nginx to run it, on AWS.
